# Reloj Mundial 2011

Un reloj mundial que funciona en **tiempo real**, pero simula que estamos en el año **2011**. 🕐

## Características

- ⏰ Hora actualizada en tiempo real.
- 📅 La fecha muestra el año 2011.
- 🎨 Diseño minimalista con fondo gris y texto blanco.
- 🔤 Tipografía Gill Sans.
- 🌐 Funciona directamente desde el navegador.
- 💻 Hecho con HTML, CSS y JavaScript.

## Cómo funciona

El reloj utiliza la hora real del dispositivo, pero reemplaza el año actual por **2011**.

Por ejemplo:

```text
Hora real:
11:30:25

Reloj Mundial:
11:30:25
8 de noviembre de 2011
```
